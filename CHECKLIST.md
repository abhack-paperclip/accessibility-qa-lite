# Digital Content Accessibility QA — Lite

Use this before publishing a course, document, web page, or digital handout.

## Structure
- [ ] Headings follow a logical hierarchy.
- [ ] Lists use actual list structures rather than manual symbols.
- [ ] Reading/order flow makes sense when consumed linearly.

## Text
- [ ] Link text describes its destination or purpose.
- [ ] Text remains understandable when enlarged or zoomed.

## Images and media
- [ ] Meaningful images have useful alternative text.
- [ ] Decorative images are treated as decorative.
- [ ] Videos with speech have captions.
- [ ] Important visual information is available in another form.

## Tables and documents
- [ ] Tables have identifiable header relationships.
- [ ] Complex tables are minimized or explained.
- [ ] PDF/document tags, headings, and reading order are meaningful where applicable.

## Keyboard and interaction
- [ ] Important controls are reachable by keyboard.
- [ ] Keyboard focus is visible.
- [ ] Nothing traps keyboard focus.

## Final smoke test
- [ ] Test one representative page with keyboard only.
- [ ] Test one representative page with zoom/enlargement.
- [ ] Run an accessibility checker or screen reader on representative content when available.

## Important limitation

This checklist is a practical QA aid. It does not certify legal compliance, WCAG conformance, or accessibility of any specific product/content.
